# MonitoringSystemForCitadel
Программа осуществляет Мониторинг состояния linux
В конфигурационном файле устанавливаются отслеживаемые метрики, частота и вывод результата (файл, консоль).
Программа состоит из 3-х основных функций:
1) get_cpu_usage - получение информации о загруженности ядер
2) get_memory_usage - получение информации об памяти системы
3) output_metrics - вывод резльтата (в файл или консоль в зависимости от конфигурационного файла)
И одного метода parse_config - предназначенного для парсинга json файла конфигурации
